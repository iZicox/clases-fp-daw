# AGENTS.md

## Repo purpose
Teaching repository for FP DAW (Desarrollo de Aplicaciones Web). Contains class exercises and notes.

## Structure
- `frontend-javascript-css/` — JS, CSS, HTML exercises and notes
- `html-xslt-xml/` — XML, XSLT, XPath, XSD exercises
- `script-base-de-datos-oracle-xe/` — Oracle SQL and PL/SQL scripts
- `script-base-de-datos-oracle-xe/pl/` — PL/SQL exercise responses (`respuestas-*.sql`)

## Conventions
- Exercise responses follow pattern `respuestas-XX-NN-schema.sql` (topic number, exercise number, database schema)
- Git push workflow targets `main` branch
